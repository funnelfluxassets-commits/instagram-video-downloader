# InstaDownloader - Instagram Video, Reels, Photo & Audio Downloader

A modern, fast, and free online web application for downloading Instagram Reels, Videos, Photo Carousels, and MP3 audio tracks in Full HD without watermarks or third-party ads.

## Features
- **1080p Full HD MP4 & 720p HD:** Save Instagram Reels and videos with crisp merged audio.
- **Extract Audio (320kbps MP3):** Save background soundtracks or voice tracks.
- **Photo Carousel Support:** Download multi-slide photo posts in original high resolution.
- **Direct Stream Download:** Straight to device Downloads folder with custom filenames.
- **Signup Email Notifications:** Automatic signup notification alerts sent to `funnelflux.assets@gmail.com`.
- **Full SEO / AEO / GEO:** Schema.org structured data, sitemap, and robots.txt.

## Tech Stack
- **Frontend:** React 19 + TypeScript + Vite + Tailwind CSS 4 + Lucide Icons
- **Backend:** Express.js + Node.js (Vercel Serverless Function)
- **Engine:** yt-dlp standalone binary + FFmpeg static muxer
- **Auth & Database:** Firebase Auth + Firestore
